# מועמדים למלווים (VolunteerCandidates)

ניהול פניות למתנדבים בפוטנציה (מלווים) בפעמונים. מקומי, משתמשת יחידה. מפרט: `claude/spec-volunteer-spinoff-16-10.md` בפרויקט Claude.

## מצב: גרסה 0.2.0 (שלב 2)
**שלב 1:**
- ייבוא קובץ HTML שמור של "אנשי קשר" (מוסיף רק מי שעוד לא במערכת).
- שליפת פרטי כל פעיל מדפדפן ייעודי (Edge, פרופיל נפרד שנשמרת בו ההתחברות לפעמונים). הדף נקרא ונזרק, לא נשמר.
- מי ש"אפשרויות סיוע נוספות" שלו כוללת "ליווי משפחות" ← **מועמדים**. אחרת ← **לא רלוונטי**. דומה אך לא זהה ← **לבדיקה**. כשל בשליפה ← **נכשלו**.

**שלב 2:**
- שינוי סטטוס עם הערה; תאריך מעקב אוטומטי לפי ימי המעקב של הסטטוס (ברירת מחדל 5 לסטטוסים 1–5), או תאריך ידני. ב"לא מעוניין כרגע" חובה תאריך לפנייה חוזרת.
- יומן קשר לכל מועמד: פנינו / התקבלה תשובה (ווטסאפ, מייל, טלפון, אחר), הערות חופשיות ושינויי סטטוס. תיעוד פנייה בווטסאפ או תשובה מקדם סטטוס מוקדם אוטומטית (לא אחורה, לא מתוך סטטוס סיום).
- עריכת שם פרטי, שם משפחה ומגדר (התיקון נשמר גם ברענון).
- הגדרות ← סטטוסים: שם, סוג (בתהליך / סיום), ימי מעקב, חובה תאריך, הסתרה, סדר, והוספת סטטוס. כולל "לא עבר ראיון" (סיום).
- סינון ברשימה: בתהליך (ברירת מחדל, בלי סיום) / הכול / סיום / סטטוס מסוים, ו"מעקב להיום או באיחור".
- מסד נתונים מגרסה קודמת מתעדכן אוטומטית (הוספת עמודות וטבלאות בלבד).

עדיין אין (שלבים הבאים): תבניות ושליחה (3), סיכום לפעמונים, גיבוי, סיסמה, מחיקה, אריזה והתקנה (4).
**עד שלב 4 אין כניסה בסיסמה וגיבוי: להשתמש רק במחשב עם הצפנת דיסק ובנתונים מועטים.**

## הרצה (Windows)
1. פעם אחת: `.\setup.ps1`
2. הפעלה: `.\run.ps1` (או `.\run.ps1 --browser` לפתיחה בדפדפן הרגיל).
3. בשליפה הראשונה ייפתח חלון Edge: להתחבר לפעמונים. ההתחברות נשמרת בפרופיל הייעודי.

הנתונים: `%LOCALAPPDATA%\VolunteerCandidates` (מסד, יומנים, פרופיל הדפדפן). בדיקות: `.\test.ps1`.

משתני סביבה: `VC_DATA_DIR` (מיקום נתונים), `VC_BROWSER_CHANNEL` (ברירת מחדל `msedge`, אפשר `chrome`), `VC_BASE_URL`.
