# מועמדים למלווים (VolunteerCandidates)

ניהול פניות למתנדבים בפוטנציה (מלווים) בפעמונים. מקומי, משתמשת יחידה. מפרט: `claude/spec-volunteer-spinoff-16-10.md` בפרויקט Claude.

## מצב: גרסה 0.1.0 (שלב 1)
- ייבוא קובץ HTML שמור של "אנשי קשר" (מוסיף רק מי שעוד לא במערכת).
- שליפת פרטי כל פעיל מדפדפן ייעודי (Edge, פרופיל נפרד שנשמר בו ההתחברות לפעמונים). הדף נקרא ונזרק, לא נשמר.
- מי ש"אפשרויות סיוע נוספות" שלו כוללת "ליווי משפחות" ← **מועמדים**. אחרת ← **לא רלוונטי**. דומה אך לא זהה ← **לבדיקה** (הכרעה ידנית). כשל בשליפה ← **נכשלו**.
- סטטוס "חדש" ותאריך מעקב (+5 ימים) למועמד חדש; כל סטטוסי ברירת המחדל כבר בבסיס הנתונים.
- כרטיס מועמד: כל הפרטים, פתיחה בפעמונים, קישור ווטסאפ, רענון פרטים, הכרעה ידנית.

עדיין אין (שלבים הבאים): שינוי סטטוסים ויומן קשר (2), תבניות ושליחה (3), סיכום לפעמונים, גיבוי, סיסמה, מחיקה (4).
**עד שלב 4 אין כניסה בסיסמה וגיבוי: להשתמש רק במחשב עם הצפנת דיסק ובנתונים מועטים.**

## הרצה (Windows)
1. פעם אחת: `.\setup.ps1`
2. הפעלה: `.\run.ps1` (או `.\run.ps1 --browser` לפתיחה בדפדפן הרגיל).
3. בשליפה הראשונה ייפתח חלון Edge: להתחבר לפעמונים. ההתחברות נשמרת בפרופיל הייעודי.

הנתונים: `%LOCALAPPDATA%\VolunteerCandidates` (מסד, יומנים, פרופיל הדפדפן). בדיקות: `.\test.ps1`.

משתני סביבה: `VC_DATA_DIR` (מיקום נתונים), `VC_BROWSER_CHANNEL` (ברירת מחדל `msedge`, אפשר `chrome`), `VC_BASE_URL`.
